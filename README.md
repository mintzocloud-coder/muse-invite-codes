# 🎟️ Muse Invite Codes

Community board for **Muse early-access invite codes** — grab a code, or share your spare.

🌐 **Live page:** https://mintzocloud-coder.github.io/muse-invite-codes/

## How to get a code
1. Open the page above and copy any code (featured code first).
2. Redeem it in Muse's early-access / invite section.
3. Codes are first-come, first-served — if one is used up, try the next.

## How to share your code
1. Click **"Submit your code"** on the page (or [open an issue](../../issues/new?template=invite-code.yml)).
2. Put **only your invite code** as the issue title (e.g. `NOCYM9`).
3. It appears on the page automatically. Sharing is always free — never ask for payment.

## Notes
- The page reads open issues labeled `invite-code` via the GitHub API — no server needed.
- Abuse (fake codes, selling codes) → issue closed, user reported.
